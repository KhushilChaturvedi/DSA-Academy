# DSA Academy — Full Curriculum

A standalone first-principles learning companion to DSA Forge.

## Curriculum
41 concept modules across 7 areas.

Areas:
- Foundations
- Linear Structures
- Searching & Ordering
- Trees & Priority
- Graphs
- Algorithmic Patterns
- Advanced Structures

## Lesson engine
Every module uses the same interactive mental-model loop:
1. Discover the problem
2. Strip away vocabulary and understand the invariant
3. Manipulate the model
4. Predict before reveal
5. Build the smallest implementation model
6. Explain it back
7. Break it / learn its boundary / connect it

The Stack prototype's navigation issue is fixed by using one explicit Continue state machine: Continue is enabled only after the current interaction is completed and always advances the lesson stage.

## Run
Open `index.html` in a modern browser. No server, framework, package manager or API key is required.

## Relationship to DSA Forge
Academy teaches and reconstructs mental models. Forge tests whether those models transfer to unfamiliar problems.
